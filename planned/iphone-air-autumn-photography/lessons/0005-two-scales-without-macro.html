Two scales without macro

A place, then one object that belongs to it. No macro lens; closest focus, then 2× if needed.

≈8 minutes · Week 3 walk · time this for peak colour if you can

Apple’s spec sheet does not list a macro mode on iPhone Air.¹ “Close-up” therefore means: move in until autofocus hunts, step back a few centimetres until the square locks, then use optical-quality 2× if you still need tightness. If the square pulses, you are too close.

Apple does not publish a millimetre minimum-focus figure for this camera. Trust the hunt-then-step-back test, not a number from a Pro review.

Portraits on this generation include Focus and Depth Control, and they are not only for faces.¹ A Photo-mode 24MP file can also pick up depth for a later blur. Use blur only when it separates a subject from a busy playground. If the background is already a wash of colour, skip Portrait — fake-bokeh on foliage looks like a smear. Do not use 48MP if you want that depth-for-later path.

The two-scale method

  1. Photograph the place (bench + tree + block).
  2. Without walking more than a few metres, photograph one object that belongs to that place (a specific leaf, a mushroom after rain, moss on a Hinterhof wall).
  3. The pair should feel made together: same light, same Photographic Style (Standard — no sudden Bright).

Water doubles the world and gives you width the lens does not have. Expose for the highlight in the reflection (Lesson 3). Canals and puddles are neighbourhood ultra-wide.

Peak colour in Berlin is typically October, especially mid to late month, with usable colour depending on frost.² Destination parks are optional weekends. The pedagogical point is repeating the same two or three nearby blocks so the control tree from Lesson 1 actually changes.

Check yourself

Autofocus hunts on a leaf. What do you do on this phone?

There is no macro mode. Digital zoom and a 48MP crop both enlarge blur. Step back, lock, then the 52 mm crop if you still need tightness.

Assignment 3 · a diptych

One subject, two scales, same visit. Publish the pair with two captions: where, and what the detail is doing in that place. If Portrait blur does not separate, turn it off and say so — that sentence is more useful than a smear.

Retrieval practice

When should you not add Portrait blur to foliage, and why?

When the background is already a wash of colour. Blur is for separation from clutter. On already-soft autumn backgrounds it reads as a computational smear, not as depth.

If the pair does not feel related, you walked too far between frames or changed the light (a Style, a different street). Ask before adding a third image to “explain.”
