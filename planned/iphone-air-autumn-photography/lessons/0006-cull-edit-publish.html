Cull, two-minute edit, publish

A stranger should be able to read 6–8 images as a place and a season. Photos is a finisher, not a painter.

≈10 minutes · Week 4 · capstone

HEIF from Smart HDR 5 is already a finished file.¹ Aggressive edits posterise skies and make yellows neon. Overcast autumn already saturates foliage. The job is mostly not to blow the bright leaves — which you already handled at capture if Lesson 3 stuck.

Project bans (from issue #12): no fake autumn colour, no sky replacement, no Clean Up as a creative tool.

Cull the same day

On a larger screen, not the lock screen. Keep photographs, not 40 near-misses. Transfer full-resolution keepers off the phone if storage matters; the blog never gets those files.

A keeper is: horizon level, highlights not clipped on the leaves you cared about, subject nameable in five words, caption that says where and when.

Edit budget (Photos)

Apple’s Photos editor is enough for this list.² Per image, in this order:

  1. Crop / straighten / tiny perspective
  2. Exposure if the whole file is dark (dusk)
  3. Highlights down, shadows up — small
  4. Photographic Style: warmer or more intense, not both at the stops
  5. Brilliance / Vibrance a little; Saturation almost never
  6. Sharpness / Definition only if the file will be shown small on the web
  7. Compare with Original. If you cannot tell they are the same walk, you over-edited.

Export for Hugo

  • Share → Save to Files as JPEG, or duplicate and export.
  • Long edge about 1600–2500 px. 48MP originals are the wrong artefact for GitHub Pages.
  • Filename: 2026-10-12-landwehrkanal-1x.jpg style, dated.
  • Put files in static/photos/autumn-2026/ on the blog repo and reference them the way existing images do.
Assignment 4 · the set

Build one set of 6–8 images that a stranger could read as a place and a season. Write 400–800 words: where the loop is (honest, not a door-to-door invitation), what the Air cannot do, and what repeating the same blocks taught you. That is the capstone post. Earlier weekly posts can stay short.

Retrieval practice

Without looking up: why is 24MP the default on this phone, when is 2× honest, how do you protect yellow, why does panorama exist here, and what did repeating blocks show you? Write as if it were the closing paragraph of the capstone.

24MP HEIF is the Fusion file: HDR, detail, depth-for-later. 2× is honest as a 52 mm crop of the same sensor, not as digital zoom. Yellow is protected by metering the leaf and exposing down. Panorama is the one-camera ultra-wide. Repeating blocks is how light and colour become visible as change rather than as a destination postcard. If any beat was missing, that lesson is unread in practice even if the HTML was opened.

Success is not “stunning.” It is the list in MISSION.md, done on walks you already take.

After the capstone draft, bring the 6–8 JPEGs and the 400–800 words back. The teacher’s job then is whether the files support the sentences — not whether autumn looks like a commercial.
