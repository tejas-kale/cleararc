Paired email evaluation

Five short lessons for reasoning about sample size when three models classify the same hand-labelled emails.

≈40 minutes · Personal case study, not a population benchmark · 0 of 5 lessons read

The central distinction

One hundred emails can expose large differences and concrete failure patterns. It does not make a close ranking, a rare-class rate, or a calibration claim precise. The question is always: precise enough for which claim?

Source of the figures

The course uses the Wilson and illustrative paired-difference calculations in the supplied personal evaluation note and notebook. Its figures are planning aids, not power guarantees: actual class prevalence, error costs, and model disagreement remain unknown until the frozen evaluation is run.

How to use this. Answer each short check before revealing it. If your answer differs, use the explanation to locate the exact idea that moved: a proportion, a sampling distribution, a paired difference, or an independent unit.
