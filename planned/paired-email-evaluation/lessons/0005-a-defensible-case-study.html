Choose evidence for the claim

“How many emails?” has no single answer because the estimand changes with the claim.

≈6 minutes · A defensible personal case study

Five questions, five evidence needs

ClaimWhat is estimatedWhat constrains precision
One model's accuracyCorrect / emailsTotal independent emails; Wilson interval
Two models differ(b − c) / nIndependent email pairs and their discordance
Rare-class performanceCorrect / rare-class emailsRare-class count, not overall n alone
Probability qualityBrier score, log lossNumber and diversity of scored events
CalibrationConfidence versus observed frequencyCounts in each relevant confidence bin

Do not use one impressive-looking sample size to answer all five. A 200-email natural sample may make an overall accuracy interval useful while still providing only about 10 examples of a 5% class and about 40 observations per five equal-mass calibration bins.

The defensible conclusion

100 emails supports an exploratory case study. It can show large model differences, make failure cases inspectable, and provide a transparent preliminary description of this inbox. At 80/100, however, the Wilson interval spans 71.1%–86.7%; with a 20% pairwise disagreement rate, the illustrative paired-difference half-width is 8.8 points; and a 5% class has only about five cases.

200 is a stronger default. It narrows the illustrative 80% Wilson interval to 73.9%–85.0% (±5.5 points), halves neither but materially reduces ordinary uncertainty, and doubles a 5% class from about five to about ten cases. It still calls for cautious rare-class and calibration language.

300 is a further precision investment, not a magic threshold. Its illustrative accuracy half-width is 4.5 points, but a 5% class is still only about 15 emails. Expand before seeing model predictions under a rule based on label counts and duplication structure, not on which model happens to be winning.

Check yourself

Which final summary best fits this personal evaluation?

Correct. It states the scope, preserves the value of the pilot, and attaches each limitation to its relevant denominator rather than dismissing the study wholesale.

Final retrieval

Explain, in your own words, why you would begin with 100 emails but prefer 200 for the final personal comparison.

I would use 100 as a transparent exploratory sample: it can reveal large differences and concrete errors, but 80/100 has a 71.1%–86.7% Wilson interval and a 5% class yields only about five examples. At 200, common-rate uncertainty falls to about ±5.5 points and the rare-class count doubles. That is stronger evidence for a personal case study, while close rankings, rare classes, correlated threads, and calibration still need careful paired analysis and qualified claims.

The one-sentence method

Sample independent emails from a defined personal inbox population, run every frozen model on every sampled email, report counts and Wilson intervals for individual models, use paired resampling or an exact paired method for comparisons, and match every conclusion to the evidence it actually has.
