A guided course in 17 lessons

Learn causal inference through football

This course teaches you how to turn a football question into a defensible causal analysis. You will define the causal effect first, state the assumptions that connect data to that effect, and then choose an estimator.

How to use the course

Take the lessons in order if causal inference is new to you. Each lesson takes about 20 to 25 minutes and includes written exercises. State your answer before opening a suggested answer or checking the quiz.

Each lesson also has an exercise sheet of seven or eight questions, designed for a thirty-minute sitting with the worked answers held back to the end. Attempt the sheet after the lesson and before moving on.
