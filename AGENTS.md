# Repository instructions

Always use British English.

## Python idiom lookup

When doing substantive Python development (non-trivial object-oriented or functional design, not one-off scripts), read `~/.claude/PYTHON.md` — it maps code shapes to relevant chapters of *Thinking in Python* (Bruce Eckel) with fetchable URLs. Use it to explain the idiom behind what's being written, proactively when a matching shape appears and on request when the user asks "why this way?" or "explain this pattern."
